# Supermarket Chaos: Retail Empire

**Start Small. Build Big. Survive the Chaos.**

Roblox cooperative supermarket management game. Phase 62 implements a player-owned Uptown branch with separate shift/world state and a shared company wallet. Roblox Studio multiplayer and persistence verification remain pending. See [project status](docs/PROJECT_STATUS.md), the [Phase 62 checklist](docs/operations/PHASE62_UPTOWN_BRANCH_RUNTIME.md), the [documentation index](docs/README.md), and [master specification](MASTER_SPECIFICATION.md).

GitHub repository supplied by the project owner: [angesh021/supermarket-chaos](https://github.com/angesh021/supermarket-chaos).

## Quick start

Prerequisites, Studio setup, Rojo sync and local play instructions are in [the beginner setup guide](docs/operations/BEGINNER_SETUP.md). Build the place source with `rojo build default.project.json -o build.rbxlx`, or connect the Studio Rojo plugin to `rojo serve` for live sync.
