# Supermarket Chaos: Retail Empire

**Start Small. Build Big. Survive the Chaos.**

Roblox cooperative supermarket management game. Source milestones through Phase 61 include several implemented feature increments; remaining runtime work and Studio verification are tracked per milestone. The current playable server still runs one owner and one neighborhood store profile; multi-store persistence and wallet foundations are in place, while the second live branch remains under development. See [project status](docs/PROJECT_STATUS.md), the [documentation index](docs/README.md), and [master specification](MASTER_SPECIFICATION.md).

GitHub repository supplied by the project owner: [angesh021/supermarket-chaos](https://github.com/angesh021/supermarket-chaos).

## Quick start

Prerequisites, Studio setup, Rojo sync and local play instructions are in [the beginner setup guide](docs/operations/BEGINNER_SETUP.md). Build the place source with `rojo build default.project.json -o build.rbxlx`, or connect the Studio Rojo plugin to `rojo serve` for live sync.
